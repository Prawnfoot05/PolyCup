# PolyCup for PolyModLoader

PolyCup 0.6.7, by Kiki. Ranked and casual multiplayer for PolyTrack 0.6.3, built with PolyModLoader.

One-round ranked races, casual FFA and teams, practice while queued, match replays, track leaderboards, and player profiles with social features and unlockable rewards.

[Play in your browser](https://polycup.online/) · [Discord](https://discord.gg/BpZp5sZ5jg) · [Changelog](CHANGELOG.md)

Uses the same PolyCup accounts, ranked queue, casual lobbies and progression as [polycup.online](https://polycup.online/). Native PML menus remain available; physics-altering mods are incompatible with ranked.

## Install

Use PML's Mod Library, or import this URL through Mods → Add:

```text
https://cdn.polymodloader.com/gh/Prawnfoot05/PolyCup/main/dist
```

Apply/reload after installation. The current package is **0.6.7** for PolyTrack **0.6.3**; [the distribution manifest](dist/manifest.json) identifies the latest release if the library/CDN is still showing a cached version. Older release files are retained for existing installations.

[Standalone client source and build instructions](https://github.com/Prawnfoot05/polycup-client). This repository distributes the PML package.

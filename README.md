# PolyCup

PolyCup 0.6.2 for PolyModLoader / PolyTrack 0.6.3, by Kiki. Shares accounts, ranked matchmaking, casual lobbies and progression with [polycup.online](https://polycup.online).

Import through PML's Mod Library or Mods → Add:

```text
https://cdn.polymodloader.com/gh/Prawnfoot05/PolyCup/main/dist
```

Choose 0.6.2 explicitly if the CDN or library still shows a cached version, then Apply/reload. Native PML menus remain available. Extra mods that change physics are not compatible with ranked.

[Client source and build instructions](https://github.com/Prawnfoot05/polycup-client) · [GPL-3.0-or-later](LICENSE.md). Older release files are retained for existing installations.
